# Ритм

«Ритм» — персональный трекер привычек для Telegram Mini Apps. В нём можно создавать и редактировать привычки, отмечать выполнение за сегодня или за прошлые дни, смотреть прогресс по дням и серии выполнения.

При первом запуске доступны три примера. Данные хранятся локально в браузере или WebView Telegram на текущем устройстве. Интерфейс подстраивается под светлую или тёмную тему Telegram и использует тактильный отклик в клиентах, которые его поддерживают.

## Запуск в браузере

Из каталога проекта выполните команду с Python 3 и откройте [localhost:8081](http://localhost:8081).

```bash
python -m http.server 8081 --bind 127.0.0.1 --directory dist
```

## Подключение в Telegram

1. Разместите содержимое `dist` на HTTPS-хостинге, доступном пользователям бота.
2. Создайте бота в [@BotFather](https://t.me/BotFather) или выберите существующего.
3. Запустите `/setmenubutton`, выберите бота и укажите HTTPS-адрес и текст кнопки «Открыть Ритм».
4. Откройте чат с ботом и запустите приложение из меню.

Для запуска через кнопку меню достаточно статической страницы. Токен бота в коде приложения не используется. [Документация Telegram Mini Apps](https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button)
